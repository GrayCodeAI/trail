# Trail field evidence ledger

Store redacted Phase 0 observations here. Do not store credentials, customer data, proprietary source code, raw production logs, or material outside the participant's consent.

## File convention

```text
YYYY-MM-DD-E###-short-slug.md
```

Use stable evidence IDs such as `E001`. A participant, organization, repository, or customer should have a research alias rather than its real name unless publication was explicitly authorized.

## Evidence rules

1. One entry may challenge rather than support the thesis.
2. Record source and event time separately from note time.
3. Mark participant recollection separately from inspected artifacts.
4. Do not generalize one workflow into a market claim.
5. Link metrics to their calculation and raw redacted observation.
6. Honor withdrawal by removing payloads and retaining only the permitted tombstone/audit fact.
7. Re-review claims when later evidence conflicts.
